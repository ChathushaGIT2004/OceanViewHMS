 # Ocean View HMS

## Overview
**Ocean View HMS** is a comprehensive Hotel Management System designed to streamline hotel operations, manage guests, bookings, billing, and services efficiently. The system leverages modern Java-based technologies, follows an MVC architecture, and implements a relational database for robust data management.

This project was developed as a part of professional software development coursework and showcases practical implementation of object-oriented design, modular programming, and service-oriented architecture.

---

## Features
- **Guest Management:** Add, update, and delete guest details.
- **Room Booking:** Real-time room availability, booking, and check-in/check-out management.
- **Billing & Payments:** Generate bills, handle payments, and maintain transaction history.
- **Service Management:** Track additional services like dining, spa, and other guest requests.
- **Reports:** Generate reports for billing, room occupancy, and guest history.
- **Role-based Access:** Admin, Receptionist, and Staff roles with restricted access.

---

## Tech Stack
- **Backend:** Java 17, MVC Design Pattern
- **Database:** MySQL (Relational Database)
- **DAO Layer:** For database interactions
- **Services Layer:** Business logic management
- **Frontend:** JavaFX / Swing (if GUI included)
- **Build Tool:** Maven
- **Version Control:** Git & GitHub
